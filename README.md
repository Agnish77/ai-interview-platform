
# AI Interview Platform

[![CI](https://github.com/agnish77/ai-interview-platform/actions/workflows/ci.yml/badge.svg)](https://github.com/agnish77/ai-interview-platform/actions)

An AI‑powered interview preparation platform that analyses your resume against a job description, identifies skill gaps, generates tailored questions, and simulates live mock interviews with real‑time feedback.

**Live Demo:** [ai-interview-platform-tau-blush.vercel.app](https://ai-interview-platform-tau-blush.vercel.app)

## Features

- **Resume Analysis** – Upload a PDF resume and job description to get a match score and skill‑gap report.
- **Streaming AI Resume Generation** – Watch a tailored resume appear live, character‑by‑character, via Server‑Sent Events.
- **Personalised Interview Questions** – Get technical and behavioural questions generated by Google Gemini.
- **Real‑Time Mock Interviews** – WebSocket‑powered interview rooms with a 2‑minute timer, auto‑submission, and AI‑rated feedback.
- **Secure Authentication** – Dual‑token JWT auth (access + httpOnly refresh tokens), password hashing, and Zod input validation.
- **Session History** – Revisit past interviews and track your progress.
- **Full Test Suite & CI/CD** – Unit, integration, and E2E tests (Jest, Supertest, React Testing Library, Playwright) running automatically via GitHub Actions.
- **Dockerised** – Single‑command run with `docker-compose up`.

## Tech Stack

**Frontend:** React 19, Vite, SCSS, Axios, React Router v7  
**Backend:** Node.js, Express, MongoDB (Mongoose), JWT, bcryptjs, Zod, Multer, pdf-parse  
**AI:** Google Gemini (GenAI SDK)  
**Real‑Time:** Socket.io, Server‑Sent Events (SSE)  
**DevOps:** Docker, GitHub Actions, Vercel (frontend), Render (backend), MongoDB Atlas (DB)

## Quick Start (Local)

1. Clone the repo and install dependencies:
   
   git clone https://github.com/agnish77/ai-interview-platform.git
   cd ai-interview-platform
   cd backend && npm install
   cd ../frontend && npm install
   ```
2. Set up environment variables:
   - Copy `backend/.env.example` to `backend/.env` and fill in your MongoDB URI, Gemini API key, and JWT secrets.
3. Run the backend and frontend:
   
   cd backend && npm run dev
   cd frontend && npm run dev
   ```
4. Open `http://localhost:5173`.

## Architecture
The backend follows a service‑repository pattern; the frontend uses a feature‑based folder structure. Real‑time features use Socket.io and SSE. All API responses follow a consistent `{ success, data, error }` envelope.
